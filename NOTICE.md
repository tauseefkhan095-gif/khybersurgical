# Project and asset notes

This is a KS website project prepared for the requester. No open-source license has been selected. The package is marked `UNLICENSED` rather than silently granting reuse rights; decide on a license before distributing it as an open-source project.

The seven WebP product images are temporary AI-generated photographic-style visuals inherited from the previous website revision. They are not supplier-certified images, real KS-stock photographs or evidence of device specifications. The site labels them as placeholders; replace them with approved product photography and check image rights before launch.

No font files are bundled. The website references Google Fonts and supplies local font fallbacks. No third-party application dependencies or copied runtime libraries are included. GitHub Actions and optional hosting/email services operate separately under their own terms.

Only an empty environment-variable template is committed. Do not commit real inbox credentials, API secrets, customer enquiries, generated local configuration or patient information.
