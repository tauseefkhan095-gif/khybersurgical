# Khyber Surgical — deploy package

This folder contains prebuilt website files. Replace the existing website files with its contents, keeping index.html at the repository root. No install/build step is needed for the existing root-hosted deployment. The supplied vercel.json preserves that deployment setup.

Contact address, call and WhatsApp links are configured. The public email is khybersurgicalindia@gmail.com. Email links open a new message in the visitor’s mail app. The inquiry form posts to FormSubmit for this inbox. After uploading, submit one test inquiry and confirm the activation email in the inbox; then submit another test to verify real delivery. The standalone preview remains email-disabled and prepares WhatsApp inquiries.

This build assumes the website is served at the domain root. A GitHub project URL /repository/ requires a rebuilt BASE_PATH; share the actual URL first.

English, Arabic, Persian and Turkish are included. Indexing remains disabled as in the original review build. The new scalpel-inspired Khyber Surgical logo is applied throughout the website, including its favicon.

See UPDATE-NOTES.md for changes and verification limits.
